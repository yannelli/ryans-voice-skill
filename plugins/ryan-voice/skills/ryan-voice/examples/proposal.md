# Proposal

Basis: Adapted from a 2020 IT proposal (names, figures, and details changed)

What to notice:
- Each problem gets a short heading ("Public Wi-Fi", "Internet Performance") and one to three sentences.
- The speed test comes first as a measurement, then "For perspective," turns it into a count of video calls.
- The vendor gets one line of reasoning: "[Vendor] access points carry no yearly license, so the library owns them outright once paid for."
- The timeline puts one task per line under period labels ("Week 1", "Week 2 to 3").
- Pricing tables show quantity, unit price, and total in cents, and one asterisk footnote covers the estimate.
- Terms are flat conditions: "If an invoice is more than 10 days late, onsite work stops until it is paid."

## Current challenges

```text
Current Challenges

An onsite review on 03/18/2026 found 4 problems that affect staff and patrons daily.

Staff Computers
The 6 staff computers run 3 different operating system versions. 2 of them no longer receive security updates.

Public Wi-Fi
3 access points cover 2 floors and the reading room. The second floor has no signal past the stairwell, so patrons there use their phones' data.

Internet Performance
The library has a single Cable line with no backup/failover. A speed test performed onsite showed 88 Mbps down and 9 Mbps up. This upload speed is not enough for the study rooms.

For perspective, one video call uses about 3 Mbps up. The current line supports 3 video calls at once, and the library has 5 study rooms.

Backups
The circulation desk computer backs up to a USB drive plugged into it. The last successful backup ran 02/27/2026 (19 days before the review).
```

## Proposed solution and timeline

```text
Proposed Solution

Staff Computers
Replace the 2 unsupported computers and update the other 4 to the same version. All 6 get the same anti-virus/malware agent and weekly patching.

Public Wi-Fi
Install 6 new access points (2 per floor, 2 in the reading room). [Vendor] access points carry no yearly license, so the library owns them outright once paid for.

Internet Performance
Add a 500 Mbps fiber line as the primary connection. The Cable line stays as the backup (if the library wants to keep paying for it).

Backups
Move to a nightly offsite backup with 30 days of history. A restore test will be performed the first Monday of each month.

Timeline

The project takes about 5 weeks. Progress notes are sent each Thursday.

Week 1
    Onsite walk-through with the branch manager.
    Equipment is ordered.
    Fiber order is placed (the carrier quotes 3 to 5 weeks to install).

Week 2 to 3
    Staff computers are replaced and updated.
    Access points are installed, one floor per day.
    Offsite backup starts, first full copy runs overnight.

Week 4 to 5
    Fiber is installed and tested.
    Old access points are removed.
    Staff walk-through of the new Wi-Fi/printing setup (30 minutes).
```
