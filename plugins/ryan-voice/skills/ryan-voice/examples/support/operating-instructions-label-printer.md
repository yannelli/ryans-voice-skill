# Operating Instructions: Label Printer

Basis: Adapted from undated equipment operating instructions (names, figures, and details changed)

What to notice:
- Each task gets a plain heading, then numbered steps with one action per step.
- "NOTE:" opens a label line, and the sentence after it starts with a capital.
- Caps subheads ("FROM THE ORDER SCREEN", "FROM A BARCODE") split one task by method.
- Steps say what the user sees after the action: "The display returns to READY."
- Conditions sit inline: "(If it shows PAUSED, press Feed once.)"

## Label printer

```text
Label Printer Operations

Printing a Shipping Label
NOTE: The printer has to show READY on the display before it'll accept a job. A red light means the roll is empty or the lid isn't latched.

FROM THE ORDER SCREEN

1. Open the order in the shipping app.
2. Check the box size and weight, then click Buy Label.
3. Click Print. The label prints within 5 seconds.
4. Peel the label and place it flat on the top of the box (away from the tape seam).

FROM A BARCODE

1. Scan the barcode on the packing slip with the hand scanner.
2. The order opens on its own. Click Print.
3. If the order already shipped, the app shows "Label already purchased" and won't print a second one.


Loading a New Roll
As with printing, the printer should show READY first. (If it shows PAUSED, press Feed once.)

1. Press both lid releases and lift the lid.
2. Remove the empty core.
3. Place the new roll so the labels feed from the bottom.
4. Pull 3 labels past the tear bar and close the lid.
5. Press Feed. One blank label comes out, and the display returns to READY.


Calibrating After a Roll Change
Do this when text prints across the gap between labels.

1. Hold Feed for 3 seconds, until the light blinks twice.
2. Let go. The printer feeds 2 to 4 labels and stops.
3. Print a test label from Settings > Printer > Test Print.
4. If the test label still prints across the gap, repeat steps 1 to 3 once, then call [Name] at 555-0167.
```
